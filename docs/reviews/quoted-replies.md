# Quoted replies

21 October 2026. Users can swipe right on a saved message to reply to it. Desktop hover and keyboard focus reveal a reply button beside the bubble. The composer shows the original author and a short preview, focuses the input, and offers Cancel reply or Escape without deleting the draft. Sending preserves the target through failed-send retries and optimistic-to-saved reconciliation. A later reply selection is not overwritten by retrying an earlier send.

Saved quotes sit inside the corresponding message bubble and identify You or the character. Tapping a quote focuses the original if it is loaded, otherwise opens the appropriate earlier-history page. Selecting Reply in earlier history returns to the latest conversation with the selection retained. Users may quote either participant's messages. Text, emoji, sticker/GIF and photo references are supported; financial system events are excluded. Archived and paused chats retain readable quotes without reply actions.

The frontend-design skill informed a restrained extension of the accepted chat: white/blush quote insets, a narrow red author rail, a matching outgoing inset, and a removable preview above the composer. The existing canvas, header, composer and typing handoff remain. Styling lives in `components/message-reply.module.css`. Gesture direction and distance distinguish a deliberate reply from vertical scrolling; cancellation and lost capture reset the gesture. Reply controls wait for hydration before accepting interaction. Keyboard focus and reduced-motion preferences are retained. Mobile screenshots were reviewed.

Migration 202610210026 stores a same-conversation reference, not a copied message body. Database validation rejects foreign, future and system-message targets. Owned thread reads resolve bounded previews, including targets outside the current history page. Reset/deletion removes references through the existing message lifecycle. Idempotence includes the original quote target, so a retry cannot silently change its referent.

All characters receive the user's explicit quote context, even when its source is outside their normal history window. Structured output offers a nullable `replyToMessageId` chosen from bounded, server-supplied recent targets. Guidance prefers normal replies and uses quotes for clarification rather than every turn. Quoted content remains untrusted past conversation, separate from current instructions and consent.
