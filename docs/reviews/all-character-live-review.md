# All-character live conversation review

22 October 2026. Requested scope: all 50 characters, including introductions, brief acknowledgements, mild flirting, changes of mood, memory and returns on another day.

## Execution

The existing configured provider generated six sequential replies for each character, using the complete published source direction. All 300 baseline replies completed. Each thread used a synthetic adult counterpart and a synthetic name. The final turn simulated a next-day return by moving earlier timestamps back one day. All 50 final baseline replies recalled the supplied name correctly; this is short-thread recall, not proof of unlimited or permanently saved memory.

A separately fingerprinted guidance revision then received one targeted recheck per character: 22 acknowledgement cases, 13 company-without-advice cases, and 15 return cases. Characters whose baseline return included a platform/memory disclaimer were prioritised for the return case. Forty-nine rechecks completed. Dele's company recheck hit the existing provider timeout and was not automatically retried. Dele's six baseline replies had completed. Total: 350 attempts, 349 completed replies, one timeout.

The independent evaluation used a $1.90 cap and the unchanged configured input/output bounds and worst-case rates. Its conservative cumulative upper bound was $1.8592; that is neither a provider invoice nor an application usage-ledger reservation. The run made a read-only configuration query and direct calls through the existing provider boundary. It created no accounts, messages, jobs or payments and changed no user settings. It evaluates model wording, not production persistence/rendering or actual background initiation. Synthetic outputs are preserved in [the evidence record](../cast-50/evaluations/conversation-momentum.json).

## Findings and changes

- Brief acknowledgements generally continued the topic, but many replies graded the user's effort or labelled them quiet, flat or mysterious. The guidance now explicitly treats a plain acknowledgement as ordinary conversation, encourages an unknown-name introduction when appropriate, and disallows effort grading or unsolicited Pidgin.
- Mild compliments too often triggered job/location biographies or questions asking the user to justify interest. Shared pacing now favours a warm personal response without an interview, biography or test of worth.
- Company-without-advice replies repeated assurances and offered silence or a menu instead of participating. A contextual reminder now asks for a gentle concrete hook from the character's tastes or supplied user interests. Several rechecks did offer music/book/film topics; some still retained repetitive reassurance or unnecessary menus.
- Name recall worked, and clear goodbyes were respected. Some return replies still invented dated routines, inferred successful sleep, or described platform memory. Shared guidance now distinguishes established character life from unavailable dated events and avoids treating a plan to sleep as proof of sleep or recovery. Previously failing return cases improved in several rechecks, but Bassey's recheck still included an unnecessary record-keeping explanation.
- Some acknowledgements remained judgmental, and Seyi still switched to Pidgin without a user cue in his recheck. These are open quality issues, not passing results.

After reviewing the rechecks, the current-turn cadence block was moved after older dialogue/lifestyle illustrations in the assembled developer instructions. This reduces conflicting example precedence. That final ordering adjustment passed offline regression checks but was **not live-retested** within this run's ceiling. The preserved baseline and recheck fingerprints must not be represented as evaluations of that later adjustment.

## Verification and limits

Focused offline checks passed for 300 momentum contexts, provider and Anthropic mapping/failures, all 50 personality contexts, Nigerian exchange selection, and 450 full-canon prompt-budget cases. An ordering regression asserts that current-turn cadence follows illustrative dialogue. Momentum checks are included in the offline core runner. Scoped lint and TypeScript were checked separately.

Agent review is complete with open quality issues. This is not native-speaker/founder acceptance, a guarantee of error-free conversation, or evidence that all personalities are already sufficiently distinct in generated wording. No model/provider switch, automatic paid retry or output rewriting was introduced.
