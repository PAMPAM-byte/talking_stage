# Adult-chat scope decision

18 October clarification: the latest requested work explicitly targets non-explicit flirting, chemistry and natural conversation. See [the conversation review](./conversation-review.md). The earlier explicit-mode proposal below is historical future scope, not a blocker for the current supported improvements.

17 October 2026. The founder explicitly requested adult chat rather than only suggestive teasing. This records a change in intended text-chat scope, superseding the earlier non-explicit product direction as a future requirement. It does not claim the feature is implemented. The machine-readable record is [content-scope.json](./content-scope.json).

The configured integration accepts Anthropic Claude Haiku models only. Anthropic's [policy effective September 15, 2025](https://www.anthropic.com/legal/archive/22742366-2ef0-4c7a-a833-6523f10d3944) prohibits sexually explicit generation and erotic chats. The [announced policy effective November 12, 2026](https://www.anthropic.com/legal/aup) retains that restriction. Both were inspected on October 17; the future effective date was not treated as already in force. Explicit generation therefore remains unavailable on this integration. No bypass instructions, provider fallback, new provider account or unmetered calls were added.

All 50 editorial profiles now include individual romantic style, pace and substantive-conversation direction, with additional original, non-graphic attraction and thoughtful-discussion examples. Shared runtime guidance strengthens continuity, reasoned opinions, mutual romantic interest, respectful retreat and changes of mood/topic. The individual draft directions still require the existing review/publication process.

To implement the requested explicit text mode, the next dependency is a provider/model whose documented terms support that use. Selection must account for the actual intended workload rather than claims that a model is merely 'uncensored'. Preserve the existing private-context, metered budget, refusal and cancellation paths when integrating it. No provider has been selected or represented as suitable by this work.

An explicit mode would also need a clear adult-only, voluntary conversation setting and immediate de-escalation controls. An onboarding adult declaration is not an explicit-mode opt-in. Preserve the current prohibition on retaining sensitive intimate details as persistent user memories. Character warmth, photos and relationship progression must remain independent of payment. These are concrete integration requirements for the requested scope; no new controls are presented as completed.

Photo scope remains non-explicit. Public product copy and older acceptance records still describe the implemented scope; do not advertise explicit capability before it exists. Native-speaker/live voice evaluation remains pending, and structured tests do not prove either naturalness or provider acceptance.
